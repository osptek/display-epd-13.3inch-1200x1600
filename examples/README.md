# 示例工程 / Sample Projects

本目录中的每个子文件夹都是一个独立的示例工程，打开后请按照该文件夹内的 README（如有）进行编译。这些工程是参考代码，引脚、背光、触摸等配置请根据实际硬件修改。选用前请对照仓库首页各型号的驱动 IC 和接口进行确认。

Each subfolder in this directory is an independent sample project. Open it and build according to the README inside (if any). These projects are reference code only — please modify pins, backlight, touch, etc. according to your actual hardware. Before choosing a project, please confirm the driver IC and interface against the model information on the repository home page.
